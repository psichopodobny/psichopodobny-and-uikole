# Artwork sources

- Left half: the user's original 1080×1080 Arima portrait with a tie, combined with the user's foggy winter landscape. Portrait and landscape are embedded losslessly. A soft transition blends only the left edge of the portrait; no face outline is cut out. This half is monochrome.
- Right half: original color K-ON! banner from https://github.com/uikoll/uikoll/blob/main/k-on.jfif. Colors are preserved.

- Heading artwork: Bahnschrift Semibold (weight 600, width 95), converted to SVG outlines for consistent rendering. Heading images include readable alternative text in the README; section links retain explicit anchors.

Portraits and nicknames stay fixed. Native SVG snow uses 60 steps per second; actual playback follows browser and display scheduling. Snow, mist and text lighting loop every 8 seconds. Rendered endpoints at 0 and 8 seconds match exactly. A GIF copy uses 20 ms moving-frame delays (50 FPS). The entire right half is pixel-identical to the previous version at the same animation phase. Image rights remain with their respective owners. No generated characters or tracking services are used. No account avatar was changed.
